# ECONOVA Snake 🐍

لعبة الثعبان الخاصة بفعالية **ECONOVA**.
اجمع 20 نقطة لتفوز. بعد الفوز أو الخسارة تظهر صفحة الفعالية:

- 📅 **التاريخ:** 17 نوفمبر
- 📍 **المكان:** كلية العلوم الزراعية والبحرية

## طريقة اللعب
- **الجوال:** اسحب على اللوحة أو استخدم أزرار الأسهم.
- **الكمبيوتر:** الأسهم أو WASD، و P أو Space للإيقاف المؤقت.
- الثمرة الحمراء = نقطة، النجمة = 3 نقاط.

## النشر على GitHub Pages
1. ارفع الملفات إلى مستودع جديد على GitHub.
2. ادخل **Settings ← Pages**.
3. في **Source** اختر `Deploy from a branch`، ثم الفرع `main` والمجلد `/ (root)`، واضغط **Save**.
4. بعد دقيقة تقريباً تشتغل اللعبة على الرابط:
   `https://<اسم-المستخدم>.github.io/<اسم-المستودع>/`
